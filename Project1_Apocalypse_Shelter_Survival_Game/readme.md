# Apocalypse Shelter Survival Game

## Description

Apocalypse Shelter Survival Game is a text-based Java game.
The player must explore the shelter, collect the required items,
and survive before time runs out.

## How to Compile

Open the project in Eclipse as a Java project and make sure
the project builds without errors.

## How to Run

Run the `PlayGame` class as a Java Application.

The game will display the available commands and ask the
player to enter commands.

## Available Commands

- `go [direction]` - Move to another room.
- `look` - Look around the current room.
- `pick up [item]` - Pick up an item.
- `drop [item]` - Drop an item.
- `inventory` - Check the player's inventory.
- `help` - Show available commands.

## How to Test

Run the JUnit test classes in Eclipse using:

Run As → JUnit Test

The tests check normal cases and invalid input cases for
the main game commands.
